For Nic and Josua · Watch the moves, then play them yourself

How to use this

  1. Press ▶ Play to watch the moves, or step with ◀ ▶ (or the arrow keys).
  2. Read the note under each move. It says why the move is good.
  3. Set up a real board and play the line yourself, without looking.
  4. Use 🔄 Flip to see the board from Black's side.

The pieces

Reading the moves

  • e4 = a pawn moves to e4.
  • Nf3 = a knight moves to f3.
  • Bxc6 = the bishop takes on c6 (x means capture).
  • O-O = castle short. O-O-O = castle long.
  • + = check. # = checkmate.
